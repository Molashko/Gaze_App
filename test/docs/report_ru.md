# Отчет о проделанной работе

## Цель

Оценить качество разработанной модели через набор модульных тестов и предоставить инструменты автоматизированного запуска.

## Выполненные работы

1. Подготовлена структура тестового контура в папке `test`.
2. Реализованы 4 тестовых модуля:
   - `test_calibration_module.py`
   - `test_gaze_features_module.py`
   - `test_head_pose_module.py`
   - `test_tracker_module.py`
3. Настроена конфигурация автозапуска:
   - `pytest.ini`
   - `test_flow_config.json`
   - `run_tests.py`
4. Создан UI-лаунчер на `PyQt5`:
   - `ui/test_runner_ui.py`
5. Подготовлена документация по тест-набору и потокам запуска.

## Результат

- Тестовый набор готов к запуску из CLI и UI.
- Поддерживается запуск:
  - полного набора
  - smoke-набора
  - отдельных модулей
- Реализован экспорт лога выполнения.

## Вывод

Сформированный тестовый контур позволяет проводить повторяемую проверку инвариантов модели и удобно демонстрировать результаты проверки в интерфейсе.
