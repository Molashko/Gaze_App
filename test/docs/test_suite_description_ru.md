# Описание тестового набора

## Назначение

Тестовый набор предназначен для проверки инвариантов ключевых частей пайплайна:

- калибровка регрессионной модели
- извлечение признаков взгляда
- расчет позы головы
- оркестрация в трекере

## Состав модулей

## 1) `test_calibration_module.py`

Проверяет:

- минимальный порог сэмплов для `fit`
- поведение `predict` до калибровки
- корректность `fit/predict` на синтетических данных
- создание RANSAC-регрессора

## 2) `test_gaze_features_module.py`

Проверяет:

- корректность `_weighted_mean`
- границы и устойчивость `_eye_quality`
- поведение `extract_gaze_features` при отсутствии данных
- корректность взвешенного объединения по двум глазам

## 3) `test_head_pose_module.py`

Проверяет:

- диапазон нормализации углов
- поведение `estimate_head_pose` при ошибке `solvePnP`
- успешную ветку расчета с моками OpenCV
- fallback на нули при исключениях

## 4) `test_tracker_module.py`

Проверяет:

- форму и тип feature-вектора
- обновление флага `calibrated`
- поведение `predict_screen` без калибровки
- clipping и масштабирование экранных координат
- цепочку сглаживания `median -> one euro`

## Ограничения

- Тесты выполняются на уровне unit и не требуют физической камеры.
- OpenCV/MediaPipe тяжелые ветки в ряде мест замещаются моками.
